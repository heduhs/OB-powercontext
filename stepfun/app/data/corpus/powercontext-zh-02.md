PowerContext 是什么。· *PowerContext 是一个面向 AI Agent 的开源上下文服务。** 它把工作里值得长期保留的部分——已经确认的决定、约束、证据、进展——从某一次对话里搬出来，这样下一个会话、下一个 Agent、或者下一个接手的人，都能从当前进展继续，而不必重读全部记录。 可以把 PowerContext 理解为三层，也可以直接使用完整 Server 或把同一套契约嵌入其他应用： 层 负责什么 适合什么时候使用 --- --- --- Core protocol Source、Artifact、Trigger 抽象契约 嵌入 PowerContext 或扩展组件 Builtin runtime Memory、Handoff、Experience、Skill 服务，以及调度、推理和受支持的存储后端 运行标准本地 Server Server 与 integrations HTTP/MCP、Python Client、CLI、Dashboard 和 Agent 插件 接入 Agent 或应用 工作很少会由开始它的人或 Agent 独自完成。你把任务交给 Agent，Agent 推进一部分，之后可能由你或其他人接手。推理过程和当前状态却常常留在那段对话里。PowerContext 把它们从对话里移出来，变成可以查看、带版本号的 Artifact： 每一项内容都属于一个 **Scope**——一条独立的 Source 日志、一套 Memory 生命周期、一个评审收件箱和一份 Handoff 历史。Scope ID 只用于选取数据，它不证明用户身份、不授予工具访问权限，也不授权执行。 · 下面两张 Dashboard 截图使用的是合成演示记录。*
